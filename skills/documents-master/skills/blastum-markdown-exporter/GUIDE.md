# Markdown Exporter

CLI tool to convert markdown files to 15+ output formats.

## Prerequisites

Install once via `uv tool install md-exporter` or `pip install md-exporter`.

## Quick Reference

All tools follow: `markdown-exporter <tool> <input> <output> [options]`

| Tool | Output |
|------|--------|
| `md_to_docx` | Word (.docx) |
| `md_to_pdf` | PDF (.pdf) |
| `md_to_html` | HTML file (.html) |
| `md_to_html_text` | HTML to stdout |
| `md_to_png` | PNG image(s) |
| `md_to_pptx` | PowerPoint (.pptx) |
| `md_to_xlsx` | Excel (.xlsx) |
| `md_to_csv` | CSV (.csv) |
| `md_to_json` | JSON/JSONL (.json) |
| `md_to_xml` | XML (.xml) |
| `md_to_latex` | LaTeX (.tex) |
| `md_to_ipynb` | Jupyter Notebook (.ipynb) |
| `md_to_md` | Markdown file (.md) |
| `md_to_codeblock` | Code files by language |
