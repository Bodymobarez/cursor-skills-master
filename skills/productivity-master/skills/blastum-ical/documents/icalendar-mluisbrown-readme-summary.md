## Key Facts

- **Scope:** **Minimal** Swift parser for RFC **5545**, **VEVENT-only** in current README.
- **Parsed VEVENT properties (only):** `DTSTART`, `DTEND`, `UID`, `DESCRIPTION`, `LOCATION`, `SUMMARY`.
- **Motivation (README):** `.ics` used by **holiday rental / booking** channels (Airbnb, Booking.com, Wimdu cited).
- **Repo:** `https://github.com/mluisbrown/iCalendar` (default branch **master** per GitHub API when fetched).
- **License:** MIT (per GitHub repo metadata; not repeated in short README body).

## Section Digest

Single short README: positions the library as intentionally narrow for accommodation-calendar interchange, not a general full-calendar implementation.
